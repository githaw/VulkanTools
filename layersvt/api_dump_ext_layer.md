# VK_LAYER_LUNARG_api_dump_ext
The `VK_LAYER_LUNARG_api_dump_ext` utility layer prints subpass timing and submit tracing to stdout. It is compatible with Windows, Linux, macOS, and Android.

For an overview of how to configure layers, refer to the [Layers Overview and Configuration](https://vulkan.lunarg.com/doc/sdk/latest/windows/layer_configuration.html) document.

The API Dump Extension Layer can be enabled using the [Vulkan Configurator](https://vulkan.lunarg.com/doc/sdk/latest/windows/vkconfig.html) included with the Vulkan SDK.

## Layer Options

This layer does not currently define custom options.
